# 冷蔵庫レシピ提案アプリ

1. アクティビティ
2. タスク
3. ウォーキングスケルトン
4. タスクリスト
5. 便利にする

- 食材を登録する #自炊する人
  - 食材をメモする
    - [x] 食材名を入力して追加する
      - 数量と賞味期限も入れる
        - 入力の途中で候補を出す
  - 冷蔵庫の中身を確認する
    - 食材を一覧で見る
      - アプリを閉じても残す（SQLite に保存）
        - 期限が近いものを目立たせる
  - 使った食材を消す
    -  [x] 選んで削除する
       - 使い切ったらチェックを付ける
- レシピを探す #自炊する人
  - [x] 食材からレシピを探す
    - [x] 食材を Gemini API に送って、レシピをもらう
       - 先に使いたい食材を選ぶ
         - 足りない食材だけ買い物リストにする
  - 候補から選ぶ
    - [x] 候補を一覧で見る
      - [x] 3件くらいに絞る
        - 好き嫌いを反映する
- 料理する #自炊する人
  - [x] 手順を見て調理する
    - [x] 手順を画面に出す
      - 人数に合わせて分量を計算する
        - タイマーを使う
- レシピを残す #自炊する人
  - 気に入ったレシピを保存する
      - v お気に入りに入れる
  - 保存したレシピを見返す
      - v 保存したレシピを一覧や検索で探す
        - 見た履歴を残す
